# Sistem Panen

## Deskripsi

Sistem Panen merupakan program Python sederhana yang digunakan untuk menghitung total hasil panen berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga dilengkapi dengan fitur perhitungan diskon untuk membantu menghitung total harga setelah mendapatkan potongan.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal pada perangkat.
2. Clone repository ke komputer atau buka proyek melalui Google Colab.
3. Jalankan file `program.py`.
4. Masukkan nama petani, jumlah panen, harga per kilogram, dan persentase diskon sesuai dengan perintah yang ditampilkan.
5. Program akan menampilkan total hasil panen sebelum dan setelah diskon.
